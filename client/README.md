# MetaModels — Web Client

React 19 + Vite single-page app for the MetaModels marketplace.

```bash
cp .env.example .env   # add Supabase + API URL credentials
npm install
npm run dev             # http://localhost:5173
npm run build           # production build → dist/
npm run lint            # ESLint
```

See the [root README](../README.md) for full setup (Supabase, Pinata, API server).
